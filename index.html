Безопасность и архитектура

Zero-Knowledge & Client-Side: Сервер не хранит и не видит ваши секреты. Все операции происходят исключительно внутри браузера через аппаратный Web Crypto API.

Сквозное шифрование: Ключ формируется функцией PBKDF2 (SHA-256, 600 000 итераций) с криптографической солью, а данные шифруются по стандарту AES-GCM (256 бит).

Почему сервер ничего не получает: Зашифрованный пакет передаётся в URL через хэш-фрагмент (после символа #). По стандартам HTTP эта часть URL никогда не отправляется на сервер и не попадает в сетевые логи.
